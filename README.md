## 🎨 Customization Guide

### Change Brand Colors

Edit `styles.css` or `advanced-styles.css`:

```css
:root {
    --primary-teal: #00A79D;      /* Your brand color */
    --primary-teal-dark: #008C84; /* Darker shade */
    --primary-teal-light: #33BFB6; /* Lighter shade */
}
```

### Add Your Products

1. **Update product cells in HTML:**
```html
<div class="product-cell" data-product-id="YOUR_SKU">
    <div class="product-image-placeholder">
        <img src="your-image.jpg" alt="Product">
    </div>
    <div class="product-info">
        <div class="product-sku">YOUR_SKU</div>
        <div class="product-desc">Your Product Name</div>
        <div class="product-price" data-price="299.99">$299.99</div>
        <div class="product-rating">★★★★★</div>
    </div>
</div>
```

2. **Add price data attribute for currency conversion:**
```html
<div class="product-price" data-price="299.99">$299.99</div>
```

### Customize Discount Tiers

Edit `advanced-features.js`:

```javascript
calculate(unitPrice, quantity) {
    let discount = 0;
    if (quantity >= 100) discount = 0.25;      // 25% off
    else if (quantity >= 50) discount = 0.20;  // 20% off
    else if (quantity >= 25) discount = 0.15;  // 15% off
    else if (quantity >= 10) discount = 0.10;  // 10% off
    // Add more tiers as needed
}
```

### Add More Currencies

Edit `advanced-features.js`:

```javascript
const CURRENCIES = {
    USD: { symbol: '$', rate: 1 },
    EUR: { symbol: '€', rate: 0.92 },
    // Add your currency:
    AUD: { symbol: 'A$', rate: 1.52 },
```

Then update the currency selector in `ui-components.html`.

## 📱 Mobile-First Responsive Design

### Design Philosophy
This catalog is built with a **mobile-first approach**, meaning the base styles are optimized for mobile devices, then progressively enhanced for larger screens using `min-width` media queries.

### Responsive Breakpoints
```css
Mobile (Base):     320px - 767px  (default styles)
Tablet:            768px - 1023px (min-width: 768px)
Desktop:           1024px - 1439px (min-width: 1024px)
Large Desktop:     1440px+        (min-width: 1440px)
```

### Mobile Optimizations

#### 🎯 Touch-Friendly Design
- **44px minimum tap targets** (Apple/iOS guidelines)
- Larger buttons and interactive elements
- Increased padding and spacing for touch
- No hover effects on touch devices
- Optimized form inputs (15px+ font to prevent zoom on iOS)

#### 📐 Layout Adaptations
- **Mobile (320px+):**
  - Flat 2D view (no 3D transforms)
  - Single-column product grid
  - Stacked toolbar layout
  - Full-width modals
  - Bottom sheet panels
  - Simplified navigation

- **Tablet (768px+):**
  - 2-column product grid
  - Side-by-side toolbar
  - Floating panels (not full-width)
  - Larger typography
  - More whitespace

- **Desktop (1024px+):**
  - 3D isometric perspective enabled
  - 3-column product grid
  - Full feature set
  - Advanced animations
  - Desktop-optimized spacing

- **Large Desktop (1440px+):**
  - Maximum quality spread size (1400px × 900px)
  - Enhanced 3D effects
  - Optimal viewing experience

### Example 2: Creating Custom Discount Rules

```javascript
// Override bulk calculator
class CustomBulkCalculator extends BulkCalculator {
    calculate(unitPrice, quantity) {
        let discount = 0;

        // Custom tiered pricing
        if (quantity >= 200) discount = 0.30;
        else if (quantity >= 100) discount = 0.25;
        else if (quantity >= 50) discount = 0.20;
        else if (quantity >= 20) discount = 0.15;
        else if (quantity >= 10) discount = 0.10;

        const subtotal = unitPrice * quantity;
        const discountAmount = subtotal * discount;
        const total = subtotal - discountAmount;

        return { quantity, unitPrice, subtotal, discount: discount * 100, discountAmount, total };
    }
}

// Use custom calculator
bulkCalculator = new CustomBulkCalculator();
```

## 🆘 Troubleshooting

### Common Issues

**Q: Search not working?**
A: Ensure JavaScript is enabled and check browser console for errors.

**Q: Dark mode not persisting?**
A: Check that localStorage is enabled in your browser.

**Q: Currency not converting?**
A: Verify products have `data-price` attributes set.

**Q: Keyboard shortcuts not working?**
A: Click anywhere on the page to focus, avoid having form inputs selected.

**Q: Performance issues?**
A: Disable animations in advanced-styles.css or reduce product count.
